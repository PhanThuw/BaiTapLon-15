# README – Trang tạo yêu cầu bảo trì FixFlow

## 1. Giới thiệu

Trang tạo yêu cầu bảo trì là một chức năng của website FixFlow, giúp người dùng gửi yêu cầu sửa chữa thiết bị khi gặp sự cố.

Người dùng có thể nhập thông tin thiết bị, mô tả lỗi và gửi yêu cầu để hệ thống lưu lại.

## 2. Công nghệ sử dụng

- **HTML5:** Xây dựng cấu trúc biểu mẫu.
- **CSS3:** Thiết kế giao diện trang web.
- **JavaScript:** Xử lý sự kiện và kiểm tra dữ liệu.
- **LocalStorage:** Lưu thông tin yêu cầu trên trình duyệt.
- **SessionStorage:** Kiểm tra thông tin phiên đăng nhập.

## 3. Các chức năng chính

- Kiểm tra trạng thái đăng nhập trước khi tạo yêu cầu.
- Hiển thị thông tin người dùng đang đăng nhập.
- Nhập thông tin yêu cầu bảo trì.
- Kiểm tra các trường bắt buộc và nội dung mô tả lỗi.
- Đếm số ký tự trong phần mô tả.
- Chọn ảnh thiết bị hoặc ảnh lỗi để xem trước.
- Kiểm tra định dạng ảnh và dung lượng ảnh tải lên.
- Tạo mã yêu cầu bảo trì.
- Lưu thông tin yêu cầu vào LocalStorage.
- Xóa dữ liệu đã nhập bằng chức năng đặt lại biểu mẫu.
- Đăng xuất khỏi hệ thống.

## 4. Cách chạy trang web

1. Mở thư mục chứa mã nguồn FixFlow.
2. Mở file HTML của trang tạo yêu cầu bảo trì bằng trình duyệt.
3. Đăng nhập nếu hệ thống yêu cầu.
4. Nhập thông tin thiết bị và mô tả sự cố.
5. Chọn ảnh minh họa nếu cần.
6. Nhấn nút gửi yêu cầu để kiểm tra và lưu dữ liệu.

**Lưu ý:** Trang sử dụng LocalStorage để lưu dữ liệu trên trình duyệt hiện tại, chưa đồng nghĩa với việc dữ liệu đã được lưu vào máy chủ.
